# [CP-01] Registro de cuenta con datos válidos

### Descripción
Verificar que el sistema permite registrar una cuenta de práctica cuando se ingresan datos válidos en todos los campos obligatorios.

### Precondiciones
- El usuario debe estar en la página principal de “Registro de usuarios”.
- El sistema debe iniciar sin registros temporales previos (Cantidad = 0).
- Usar la versión v2 corregida para la evidencia de resultado esperado; el mismo caso también funciona en la app original v1.

### Datos de prueba
- Nombre: `Ana`
- Correo electrónico: `ana@example.com`
- Contraseña ficticia: `Abcd1234` (8 caracteres)

### Pasos a seguir
1. Pulsar **Reiniciar prueba** y comprobar que hay 0 registros.
2. Escribir `Ana` en el campo **Nombre**.
3. Escribir `ana@example.com` en **Correo electrónico**.
4. Escribir `Abcd1234` en **Contraseña de práctica**.
5. Pulsar **Registrarse**.
6. Revisar el mensaje y el panel de resultados.

### Resultado esperado
- El estado cambia a **“Registro exitoso”** y se muestra en verde.
- **Cuenta creada en este intento:** `Sí`.
- **Registros temporales actuales:** `1`.
- **Último registro temporal:** `Cuenta 1 · Ana · ana@example.com`.
